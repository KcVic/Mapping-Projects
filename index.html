ABUJA FLOOD RISK MAP

Historical & Predictive Analysis

Methodology Abstract

This map identifies high-risk flood zones within the Abuja Municipal Area Council (AMAC). Data is derived from a multi-criteria decision analysis using the Analytic Hierarchy Process (AHP).

Variables include Slope Orientation, Drainage Density, and Soil Infiltration rates. Regions marked in red represent zones with a vulnerability index score exceeding 0.75.
